\section{Conclusion}
\label{sec:conclusion}

We asked whether networks that learn from raw sensor sequences can match or
beat hand-engineered degradation features for predicting the remaining
useful life of FD001 engines, and answered it under one protocol: splits by
engine, every statistic refitted inside each fold, hyperparameters chosen by
cross validation, and the test set scored once per phase.

On the test set the answer is that they match it. The selected XGBoost on
engineered features reaches an RMSE of 15.36 cycles and the selected
Transformer on 30-cycle sensor windows $15.37 \pm 0.66$ over five seeds,
with a bootstrap interval for their difference that is centred on zero. The
Transformer's lead in cross validation did not carry over. The two
approaches differ in where their errors fall rather than in how large they
are overall: the networks are more accurate within 50 cycles of failure,
where maintenance is decided, and less accurate between 51 and 100 cycles,
where degradation first becomes visible. Combining the two inputs did not
help: the two-branch hybrid is no better than the Transformer alone on the
test set. The residual hybrid, XGBoost corrected by a Transformer, has the
lowest test RMSE (15.13) but was not the model selected by cross validation,
so we report it without choosing it.

Two steps would test these conclusions further: a window length chosen by
cross validation before the test set is opened, since a 50-cycle window
helped in the ablations; and the multi-condition subsets FD002 to FD004,
where regime normalisation and longer histories matter more. With only 100
test engines the intervals span several cycles, so any gap of a cycle or
less between two models should be read as a tie.
